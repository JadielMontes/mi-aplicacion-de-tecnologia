# TechStore — laboratorio HTML y CSS para pasantes

Proyecto educativo **ficticio**, sin JavaScript ni backend. Se puede abrir directamente con doble clic en `index.html`.

## Objetivo
Comprender cómo se conectan cinco páginas HTML, cómo comparten un CSS y cómo ampliar un sitio web sin copiar soluciones completas.

## Archivos
- `index.html`: inicio.
- `productos.html`: catálogo.
- `detalle.html`: ficha de producto.
- `nosotros.html`: información ficticia.
- `contacto.html`: formulario visual (NO envía datos).
- `styles.css`: estilos compartidos.
- `img/hero.svg`: ilustración local.

## Tareas obligatorias
Busca `TAREA` en los archivos. Realiza las 19 tareas numeradas, más la tarea 20 de revisión final. No borres comentarios hasta haber terminado.

1. Cambia la marca en las cinco páginas.
2. Personaliza el pie de página en las cinco páginas.
3. Cambia el título y descripción de inicio.
4. Añade una tercera tarjeta de beneficios.
5. Crea sección de ofertas con dos tarjetas.
6. Añade cuatro productos nuevos al catálogo.
7. Usa imágenes locales en dos productos (incluye textos `alt`).
8. Agrega una tabla HTML de categorías.
9. Completa cuatro especificaciones del producto.
10. Crea preguntas frecuentes en detalle.
11. Escribe una historia ficticia de la tienda.
12. Añade dos perfiles ficticios de equipo.
13. Explica `label`, `for`, `id`, `name`, `required`, `type`.
14. Agrega un `select` de motivo de contacto.
15. Añade horarios ficticios y enlaces de navegación.
16. Modifica cinco colores de la paleta CSS.
17. Crea estilo `:hover` para botones.
18. Cambia borde, relleno y sombra de tarjetas.
19. Revisa y mejora la vista móvil.
20. **Revisión final:** prueba las cinco páginas, todos los enlaces, imágenes y el formulario; documenta al menos tres cambios y un problema solucionado.

## Preguntas de comprensión
- ¿Qué diferencia existe entre `<head>` y `<body>`?
- ¿Qué hace `href`? ¿Qué hace `src`?
- ¿Qué diferencia hay entre `class` e `id`?
- ¿Qué son `margin`, `padding` y `border`?
- ¿Por qué `styles.css` afecta a las cinco páginas?
- ¿Por qué el formulario no envía información?

## Entregables
1. Carpeta con los archivos modificados.
2. Capturas de inicio, catálogo y contacto (escritorio y móvil).
3. Respuestas breves a las preguntas de comprensión.
4. Enlace al repositorio de GitHub; opcionalmente publicar con GitHub Pages.

## Reglas
- Solo datos e imágenes ficticios o autorizados.
- No publicar información personal de menores, de clientes ni de la empresa.
- Cada pasante debe elegir su propia marca y colores.
- No es necesario instalar dependencias ni crear cuentas externas para editar.
